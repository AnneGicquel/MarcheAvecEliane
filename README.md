# MarcheAvecEliane ♡

## Project Overview 👀

This project focuses on creating a solution to ensure the safety and well-being of elderly individuals. The primary feature is a centralized calendar that lists all the outing needs of the elderly, managed by the association "Les Petits Frères des Pauvres". This calendar enables volunteers to sign up as companions for elderly outings, while still preserving their autonomy.

## Inclusive Approach 🫴

The project is designed with an inclusive approach, allowing volunteers to position themselves based on the specific needs of the elderly. This creates a supportive and caring community. This approach helps the elderly regain their independence and reconnect with their social lives, while also strengthening intergenerational bonds within the community.

## Main Feature: Outing Request Management Page ⭐️

The core feature of this project is the "Outing Request Management Page" for the admin. The admin is in direct contact with the elderly, enabling them to receive outing requests, create new outings, and modify or delete existing ones. 

## Features

- **Centralized Calendar**: Lists all the outing needs of the elderly.
- **Volunteer Engagement**: Allows volunteers to sign up as companions for outings.
- **Outing Request Management**: Admin can create, modify, and delete outing requests.
- **Responsive Design**: Ensures the site is accessible on all devices.
- **A11y Implementation**: Accessibility features are currently being added.
